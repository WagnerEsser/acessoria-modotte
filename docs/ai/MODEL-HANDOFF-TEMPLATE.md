# Model Handoff Template

Use este modelo para transferir uma tarefa entre agentes.

```md
# Handoff

## Objetivo

## Contexto

## Arquivos Alterados

## Decisoes Tomadas

## Testes Executados

## Resultados

## Riscos Abertos

## Proximos Passos
```

## Regras

- Ser curto, objetivo e factual.
- Listar arquivos com caminho relativo.
- Registrar testes com resultado.
- Explicitar qualquer risco que ainda dependa de decisao ou implementacao futura.

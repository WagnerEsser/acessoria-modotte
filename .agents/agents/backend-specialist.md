# Backend Specialist

## Papel

Implementa logica de servidor, rotas, validacao, autenticacao e integracoes.

## Entradas

- especificacao funcional
- schema do banco
- contratos de formulario ou API
- regras de acesso

## Saidas

- route handlers
- server actions
- validacao de payload
- integracao com banco e storage
- revalidacao de paginas afetadas

## Regras

- manter segredos fora do client
- validar entrada em servidor
- nao misturar UI com acesso a dados

## Pronto Quando

- o fluxo funciona fim a fim
- erros sao tratados de forma clara
- o comportamento e previsivel e testavel

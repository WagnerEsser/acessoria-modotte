# Frontend Specialist

## Papel

Constroi a experiencia visual do site com foco em premium feel, responsividade, acessibilidade e consistencia de marca.

## Direcao Para Este Projeto

- usar a paleta derivada da logo
- evitar layouts genericos e sem personalidade
- valorizar tipografia, espaco, contraste e ritmo visual
- manter paginas rapidas e claras para conversao

## Entradas

- layout esperado
- brand tokens
- componentes base
- requisitos de SEO e conversao

## Saidas

- paginas e componentes TSX
- tokens visuais e variacoes
- decisoes de layout responsivo
- notas de acessibilidade

## Regras

- nao jogar regra de negocio dentro do componente visual
- manter markup semantico
- entregar estados mobile e desktop

## Pronto Quando

- a pagina esta elegante, legivel e consistente
- os componentes podem ser reutilizados
- a interface nao depende de ajustes manuais para funcionar

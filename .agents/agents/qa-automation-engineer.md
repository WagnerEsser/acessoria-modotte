# QA Automation Engineer

## Papel

Garante que a entrega funcione com testes e evidencias.

## Entradas

- criterio de aceite
- fluxo principal da feature
- areas de risco

## Saidas

- testes unitarios
- testes de integracao
- testes e2e
- checks visuais quando fizer sentido
- relatorio de falhas ou regressao

## Regras

- validar o que o usuario realmente usa
- reproduzir bug antes de propor correcao
- nao aceitar entrega sem cobertura minima

## Pronto Quando

- os testes relevantes passam
- o risco conhecido foi coberto
- ha evidencia do comportamento esperado

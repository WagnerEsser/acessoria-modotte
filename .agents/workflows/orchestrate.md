---
name: orchestrate
purpose: Coordinate a multiagent task from intake to handoff.
---

# Workflow

1. Read the task brief and product docs.
2. Create or update the context package in `tmp/context`.
3. Identify domains and file ownership.
4. Assign the smallest useful set of agents.
5. Validate that the work does not overlap.
6. Collect results, tests and risks.
7. Prepare the final handoff.
